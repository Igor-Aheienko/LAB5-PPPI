# LAB5-PPPI

📌 Лабораторна робота №5
Командна розробка в Git
📖 Опис проєкту

Цей проєкт створений у рамках лабораторної роботи №5 з метою опанування навичок командної роботи з Git та GitHub.

У проєкті реалізовано клас Calculator, який містить набір математичних методів. Кожен учасник команди відповідає за реалізацію окремого методу.

🎯 Мета роботи
Навчитися працювати з системою контролю версій Git
Освоїти командну розробку через GitHub
Навчитися створювати та використовувати гілки (branches)
Практикувати роботу з pull request
Отримати досвід вирішення merge-конфліктів
